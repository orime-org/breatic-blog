# Breatic Journal working agreement

- This repository owns the independent public blog. Do not modify the product application, homepage repository, or production services as part of blog work.
- Use English for public content, commits, pull requests, and comments. Preserve the Breatic brand and the product's source-available / Elastic-2.0 positioning.
- Work on a `codex/` branch and use a pull request after the initial repository bootstrap. Do not publish unverified feature claims or private information.
- Keep permanent article filenames stable. Draft posts must not appear in generated routes, feeds, or sitemaps.
- Run the production build and `npm run check:site`; visually check desktop/mobile article and index pages before publishing layout changes.
- Do not deploy a custom domain until its DNS and HTTPS readiness are verified. Never embed secrets in the static site.
